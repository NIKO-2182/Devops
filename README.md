## 🚀 Getting Started

1. **Clone the repo**

   ```bash
   git clone https://github.com/your-username/devops.git
   cd devops
   ```

2. **Pick a guide** – open the folder that matches what you need (`kubernetes`, `scripts`, …) and read the `.md` file.

3. **Run / adapt** – most scripts are self‑contained; just tweak the variables at the top to match your environment.
